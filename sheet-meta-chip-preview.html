案3（ラベルチップ）の文字装飾バリエーション

土台は前回モックの案3と同じ：.os-line .k を display:inline-block / background:#f0efec / color:#8a8578 / font-size:9.5px / border-radius:3px / padding:0 4px / letter-spacing:0.5px。
以下のA〜Pは、この土台に対して文字まわり（太さ・色・字間・下地・形）だけを変えたもの。値側の書式（標高: 50m ／ 比高: 25m を1行に結合、住所にもラベル）は全バリエーション共通で、比較の変数を装飾だけに絞っている。
実寸：端末幅375px、テキスト側166px、.os-line は 11px / 2行クランプ。値は castle.js の実データ書式。
