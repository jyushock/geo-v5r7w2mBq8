# コンパスで向きに追従するモード（モード2）の回転 検証結果

`node tests/heading-smoother-sim.js 30` の出力（乱数30通り）。旧＝変更前の app.js（イベントごとの平滑化＋毎フレームの平滑化・2度の不感帯・0.3度未満は地図を回さない）、新＝`createHeadingSmoother`（app.js の `HEADING_SMOOTHER_BEGIN`〜`END` をそのまま読み込んで検証）。

## 目指した動き
- スマホを持っているだけなら、地図は止まって見える（センサーの揺れで小刻みに回らない）
- 向きを変えたら、すぐ付いてきて、行き過ぎて戻らない
- ゆっくり向きを変えても「止まる→急に回る」にならず、なめらかに回り続ける
- 0/360度をまたいでも逆回りに一周しない
- 60Hz と 120Hz の画面、センサーの届く頻度（20〜100Hz）で動きが変わらない

## 旧方式で起きていたこと
- 2度の不感帯：ゆっくり向きを変えると、差が2度を超えるまで止まり、超えると回る、を繰り返す（15度/秒で回すと、半分のフレームで止まっている）
- 0.3度未満は地図を回さない：回転が0.3度刻みの段付きになる（画面の角で約2.4px刻み）
- 平滑化が2段重なり、さっと向きを変えても収まるまで2.5秒かかる
- 1回ごと・1フレームごとに寄せていたので、センサーの頻度や画面のリフレッシュレートで速さが変わる

## 新方式
1. 届いた値を0/360度をまたいでも連続になるよう展開し、軽くならす（150ms）
2. 一次の遅れで追う。時定数は、差が小さいほど長く（2度以下で15秒＝ほぼ止まって見える）、大きいほど短く。センサーの値が同じ向きに8度/秒以上で0.3秒回り続けるか、6度を超える差が0.5秒続いたら「向きを変えている」とみなして、追いつくまで速く寄せる（100ms→40ms）。不感帯は設けない
3. 強さ一定の臨界減衰のばねで (2) を追い、回転の速さを途切れさせない

(2) と (3) はどちらも応答が負にならないならし方なので、向きを変え終えたところで行き過ぎて戻ることがない。計算は4ms刻みの決まった時刻で進める。

## 試験の条件
- センサー：白色の揺れ（iOS 相当1度、Android 相当3度）＋ゆっくりしたずれ（30秒、1度）。届く頻度は20/60/100Hz、間隔に±20%のゆらぎ
- 動き：静止、15度/秒でゆっくり回す、90度を0.5秒でさっと変える、0/360度をまたぐ、歩きながらの手の揺れ（±4度・1.8Hz）、磁気の乱れ（30度・0.3秒を5秒ごと）
- 画面：60Hz と 120Hz

## 指標と目標
画面の角は回転の中心から約460px なので、1度 ≒ 8px。
| 指標 | 意味 | 目標 |
|---|---|---|
| 静止中のブレ | 1秒あたりの往復した回転 | 最悪でも 0.1度/秒未満 |
| 静止中の回転（ずれ除く） | 静止中に地図が回った範囲から、センサーのゆっくりしたずれの分を除いたもの | 旧方式以下 |
| 収まるまで | 向きを変え終えてから、真の向きの±3度に収まって以後出ないまでの時間 | 平均0.8秒以内 |
| 行き過ぎ | 向きを変え終えた後、行き過ぎた角度 | 最悪でも2度未満 |
| 回転中の遅れ | 15度/秒で回している間の、真の向きとの差 | 平均8度未満 |
| 止まって見える | 回している間に地図の向きが変わらないフレームの割合 | 最悪でも1%未満 |
| 段付き | 回している間の、1フレームの回転の最大÷平均 | 平均3未満 |
| 揺れ | 歩行中・磁気の乱れのときの、真の向きとの差の RMS | 旧方式以下 |
| 60/120Hz差 | 同じセンサー値を60Hzと120Hzで描いたときの向きの差 | 0.05度未満 |

「静止中の回転」は、最初は「1度未満」としていた。しかし旧方式でも0.75〜2.3度あり、新方式で残る分も、センサーのずれに少し遅れて付いていく分と、最初の値の揺れがゆっくり抜ける分だった。そのため「旧方式以下」に改めた。往復するブレ（小刻みな回転）は別の指標で見ている。

## 気をつける点
- 磁気の乱れ（30度が0.3秒だけ出る）のとき、揺れの RMS は旧方式と同程度（3.5→3.6度）。ただし最大値は大きい（7→14度）。旧方式は全体が遅いので乱れにもほとんど付いていかなかった。新方式は0.3秒続く変化を本物の向き変えと見分けられず、半分ほど付いていく。そのかわり、本物の向き変えには旧方式の約4倍速く付いてくる
- iOS（webkitCompassHeading、真北）と Android（磁北）の基準の違い（日本で7〜9度）は今回扱っていない
