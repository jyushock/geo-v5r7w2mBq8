# 画面の使い方

この画面（`retainers/index.html`）は、地図のメニュー「一覧から検索 → 家臣団」から開きます。
ファイルをブラウザで直接開いても動きます。
表示しているデータの作り方は取得ツール側の `D:\work\SamuraiRetainers\docs\tool.md`、
データの根拠と限界は `D:\work\SamuraiRetainers\docs\data-notes.md` を参照してください。

## 家の切り替え

ヘッダの「家」で表示する大名家を切り替えます。現在は武田家のみです。

## 表示

| 表示 | 内容 |
|---|---|
| 当主別 | 武田信虎・武田信玄・武田勝頼をそれぞれの枠に分け、各当主の下に家臣を主従で入れ子にして並べます |
| 家全体 | 当主を意識しない、家中全員のフラットな一覧です。代でも主従でも分けず、並び順だけで通しに並べます。誰に仕えたかは行に出さず、ツールチップの「主君」で見ます |
| 家系 | 主従ではなく血縁でつなぎます。つながりを特定できる範囲は限られます（`docs/data-notes.md`） |

- **身分区分でまとめる** … 御一門衆・譜代家老衆などの区分ごとに畳みます。外すと2列で通しに並べます。家系では血縁でつなぐため無効になります（切り替えでボタンの位置が動かないよう、隠さず灰色にしています）
- **対象外も薄く残す** … 年で絞ったときに、その年の家中でない人物を薄く残します

## 年

年を選ぶと、その年の当主と、その年の家中に絞り込みます。「全期間」で解除します。

- 濃い字 … その年に在世していたことを確認できる
- 点線 … 生没年が欠けており、在世を確認できない
- 薄い字 … その年の家中ではない

## 検索

名前・氏族・主君・出身国・別名・身分区分に対して部分一致で絞り込みます。
氏名は「姓 名」で表示しますが、照合は空白を落として行うため、
`山本勘助` でも `山本 勘助` でも同じ結果になります。

## 行の操作

- 行の左端の `+` / `−` … 配下の開閉
- 行にマウスを乗せる … 生没年・主君・氏族・官位・区分・家紋・血縁の詳細
- 行をクリック … Wikipedia の記事を開く

## 並び順

武田二十四将を先頭に、身分区分の序列、官位の等級、生年の順で並べます。
根拠と精度は `docs/data-notes.md` を参照してください。
